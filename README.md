# CampusConnect

> **Three Problems. One Network.**
CampusConnect is a student networking platform designed to help university students find the right people to learn, build, and collaborate with.
Finding mentors, project teammates, and hackathon partners often depends on existing friend circles. CampusConnect aims to solve this by connecting students based on their **skills, interests, experience, and areas of expertise**.
---

## What is CampusConnect?
CampusConnect brings three major student collaboration needs into one platform:
- **Mentorship** — Find seniors and experienced students for guidance.
- **Projects** — Find collaborators with complementary technical skills.
- **Hackathons** — Build balanced teams by finding students with the skills your team needs.
Instead of asking *"Who do I know?"*, CampusConnect focuses on:
> **"Who has the skills I need?"**
---

## Features
### Search & Discovery
Discover students based on:
- Skills
- Technologies
- Domains
- Areas of interest
- Academic background
- Experience

### Mentorship
Connect with seniors and experienced students for:
- Technical guidance
- Career advice
- Project guidance
- Domain-specific mentorship

### Projects
Find students with complementary skills and build teams for:
- Academic projects
- Personal projects
- Open-source projects
- Startup ideas

### Hackathon Teams
Find teammates based on the skills required for a hackathon and build balanced teams beyond your immediate friend circle.

### Student Profiles
Profiles can contain information such as:
- Name
- Branch
- Year
- Skills
- Bio
- Areas of interest
- Experience

### Connections
Students can discover other users and send connection or collaboration requests.

### Posts
Students can share:
- Projects
- Opportunities
- Ideas
- Achievements
- Technical content

### Getting Started
1. Clone the Repository
- git clone https://github.com/Aditya-Pratap-Singh-Jadon/CampusConnect.git
- cd CampusConnect
  
2. Frontend Setup
- cd frontend
- npm install
- npm run dev

3. Backend Setup
- cd backend
- npm install
- npm run dev

4. Database
Database configuration and setup instructions will be added as the database layer is integrated.
